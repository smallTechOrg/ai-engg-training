# Wi-Fi

Staff connect to the network named LarkspurStaff using their normal username and password. Devices are remembered for 30 days.

Visitors use LarkspurGuest. The daily guest code is printed at the front desk and changes every morning. Guests only get internet access, not internal tools.

If your laptop drops the wireless connection repeatedly, forget the network, reconnect, and then file a Network ticket noting the room you were in.
